# Zombienet Configuration for E2E Tests

`small_network.toml` spawns:
- Rococo relay chain (`rococo-local`): validators alice (RPC 9900) and bob
- People parachain (id 1004): collator charlie

`people-chain-spec.json` is generated by `scripts/setup-network.sh` (or `build-runtime.sh`) with
`chain-spec-builder` from `devtools/runtime/people_rococo_runtime.wasm`, and is gitignored.

## Ports

Zombienet does not honor `rpc_port` for the collator in native mode: it assigns a free port and
prints it in the log. `setup-network.sh` extracts that port and writes it into `.env.e2e`; the
tests and the server read it from there.

## Manual start

```bash
cd devtools/zombienet
zombienet -p native spawn small_network.toml
```
